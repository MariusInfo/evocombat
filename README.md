A modern combat tagging and anti-PvP logging mod for **Minecraft Forge 1.20.1**.

## Features
- **Automatic Combat Tagging:** Players entering PvP combat are tagged for a configurable duration.
- **Anti-Combat Logging:** Prevents players from disconnecting during combat (triggers automated death and inventory drop penalty).
- **On-Screen Combat HUD:** Real-time visual HUD timer showing remaining combat seconds.
- **Command Blocking:** Automatically blocks teleportation and escape commands while in combat.

## Requirements
- Minecraft Forge **1.20.1** (47.4.18+)
- Java **17**
- **EvoCore** 1.0.0+
